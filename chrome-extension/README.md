# 职途助手 Chrome 扩展（MVP）

## 安装

1. 打开 `chrome://extensions/`（Edge 使用 `edge://extensions/`）。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择整个 `chrome-extension` 文件夹。
5. 固定“职途助手 · 智能表单填写”到浏览器工具栏。

## 首次使用

1. 登录并打开职途助手网站。扩展会自动同步网页中保存的可信资料。
2. 打开招聘申请页面，点击扩展图标。
3. 先点击“扫描当前页面”，检查字段来源和置信度。
4. 回答必要的未知字段，再点击“填写高置信字段”。
5. 在网站中逐项复核，手动完成最终提交。

## 当前支持

- 原生 `input`、`textarea`、`select`、单选框、复选框和 `contenteditable`。
- 常见中英文字段：联系方式、教育、实习、项目、语言、期望薪资、到岗时间和签证支持。
- React/Vue 常见受控输入框所需的 `input`、`change`、`blur` 事件。
- 未知字段答案保存在本机；下次打开职途助手时自动回写资料库。

## MVP 限制

- Workday、SAP、北森等网站的自定义下拉框、日期组件和分步表单可能需要单独适配。
- 扩展不会上传 PDF、点击验证码或点击最终提交按钮。
- Chrome 内部页、扩展商店和部分受保护页面不允许扩展注入。
